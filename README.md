# JT's Syllabus

Film recommendations built from my [Letterboxd diary](https://letterboxd.com/onebeerjt/), the Criterion Collection and university film-course syllabi, with where each one is streaming (US) from JustWatch.

Live site: https://onebeerjt.github.io/syllabus/

## How it updates

A GitHub Action (`.github/workflows/refresh.yml`) runs `scripts/fetch.py` then `scripts/build.py` and deploys to GitHub Pages:

- every day at 7am Eastern
- on every push to `main`
- on demand: **Actions → Refresh streaming data → Run workflow** (the "Refresh streaming now" link on the site goes there)

## Files

- `data/picks.json`: the recommendations (title, year, director, Criterion spine, syllabus sources, the diary film that led to it, a note)
- `data/diary.json`: my Letterboxd diary with ratings
- `data/sources.json`: the course syllabi
- `data/availability.json` and `data/posters/`: JustWatch snapshot, regenerated by `fetch.py`
- `scripts/template.html`: the page; `build.py` fills in the data

Run locally (Python 3, no packages needed):

```
python3 scripts/fetch.py && python3 scripts/build.py && open site/index.html
```
